📦 Modelos 3D para el fondo

Formatos soportados: .glb (recomendado), .gltf, .fbx, .obj — Si el modelo contiene animaciones (rig, morph, skeletal), se reproducirán automáticamente. Máximo por archivo: 10MB (optimiza con Draco/Blender).
Tip: Usa .glb para mejor compatibilidad. Los modelos .fbx/.obj se convertirán si es posible, pero sin animaciones complejas. Mantén los modelos < 10MB para carga rápida.
