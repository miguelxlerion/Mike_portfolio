Propuesta Q4 — Roadmap colaborativo

Este documento se sincroniza en tiempo real vía WebSockets (Socket.io + Redis Adapter). Cada pulsación es una operación {type, position, content} ordenada por el servidor con last-write-wins.

Qué puedes probar

  • Escribe y abre otra pestaña en /collab/ — verás el cursor remoto y el texto sincronizado (BroadcastChannel).
  • Selecciona texto y pulsa B/I/U — el formato se replica.
  • El auto-save guarda cada 2s y muestra “Guardando…” → “Guardado”.
Presencia: avatares arriba, cursores de colores y heartbeat 30s. Reconexión con cola offline.

Prueba también los comentarios a la derecha → selecciona texto y comenta.
